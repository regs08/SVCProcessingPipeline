# `tests/` — Pytest Suite

Automated tests for the pipeline. Run from the repository root with `pytest`.

## Files

### Focused unit tests

The non-parity tests cover:

- `test_run_config.py` - config resolution, placeholder guard, processing defaults, and calibration priority.
- `test_runner.py` - step dispatch edges for missing summaries and no-SIG inputs.
- `test_sig_processor.py` - truncation, metadata parsing, mixed-instrument detection, and unknown instruments.
- `test_resampler_public_api.py` - the public `process_sig_file()` dataclass API and `resample_spectra()` delegation.
- `test_processor.py` - sample-name normalization, grouping, aggregation, and ungrouped-row handling.
- `test_pipeline_demo.py` - demo-data preflight and notebook helper bounds checks.

Synthetic `.sig` snippets live under [`fixtures/sig_inputs/`](fixtures/sig_inputs/).
They are not field data and are explicitly exempted from the repo-wide `*.sig`
ignore rule.

### [`test_resampler_parity.py`](test_resampler_parity.py)
The **R-vs-Python numerical parity test**. Asserts that [`pipeline.resampler.resample_spectra`](../pipeline/resampler.py) produces values that match a reference CSV generated by the original R/`spectrolab` pipeline ([`archived_r_scripts/merge_resample_sig.R`](../archived_r_scripts/merge_resample_sig.R)) at every cell of the aligned `N_samples × 2101` matrix.

Skipped automatically when reference data is not provided, so it never blocks CI. To run it, supply:

```bash
pytest tests/test_resampler_parity.py \
    --r-reference-csv=/path/to/r_output/merged_spectra.csv \
    --r-input-dir=/path/to/processed_sig_files/
```

Or via environment variables:

```bash
R_REFERENCE_CSV=/path/to/r_output/merged_spectra.csv \
R_INPUT_DIR=/path/to/processed_sig_files/ \
pytest tests/test_resampler_parity.py
```

- Default tolerance: `MAX_ABS_DIFF = 1e-3` absolute reflectance (0.1 %). Override with `MAX_RESAMPLER_DIFF=<value>` env var.
- The test loads both CSVs through `_load_and_normalise`, which strips `.sig` / `.SIG` suffixes from sample names and coerces column headers to integer wavelengths.
- Failure messages report `max_diff`, `mean_diff`, worst-offending sample, and worst-offending wavelength, plus a hint pointing back to [`pipeline/resampler.py`](../pipeline/resampler.py) constants to check.
- Historical results documented in [`docs/parity_*.md`](../docs/) — typical max abs diff is on the order of `1e-6`.

### [`conftest.py`](conftest.py)
Defines the two pytest CLI options (`--r-reference-csv`, `--r-input-dir`) and the matching fixtures (`r_reference_csv`, `r_input_dir`). The fixtures fall back to the `R_REFERENCE_CSV` / `R_INPUT_DIR` environment variables and `pytest.skip()` cleanly when nothing is supplied.

### [`__init__.py`](__init__.py)
Empty marker — makes `tests/` importable in case of future shared helpers.

## Adding new tests
- Keep unit fixtures compact and synthetic. Real `.sig` files with GPS/location headers belong in external artifacts, not the repository.
- Optional integration tests may use the external demo artifact prepared by `scripts/prepare_demo_data.py`; skip cleanly when it is absent.
- Keep parity tolerances aligned with the values declared in [`docs/supplementary_methods.md`](../docs/supplementary_methods.md) §8.
